# Degrees prototype: hand-typed links for the six-type rule.
#
# The six link types a player can spend (each once per puzzle):
#
#   kind     a is a kind of b                    dog -> animal
#   family   a and b are the same kind of thing  lion <-> tiger
#   part     a is part of b / a is made of b     wheel -> car, glass -> sand
#   feature  a and b share a feature             tomato <-> blood (both red)
#            "red feature: tomato blood fire" links every pair in the list;
#            adjectives are never tiles, they only name what's shared.
#            List a word only if most people would give the feature as THE
#            answer to "what colour / texture / ... is X?" (snow: white; not
#            wine, fire is orange, butter isn't soft from the fridge). No
#            category words (fruit isn't sweet: lemon is a fruit), and no
#            relative features (big, small): every pair in a list is a link.
#   use      a is used for b / a makes b         hammer -> nail, bee -> honey
#   found    a is found in / with b              sand -> beach, salt -> pepper
#
# Syntax
#   kinds NAME: w1 w2 ...       each word is a kind of NAME, but NOT one family
#                               (a dog and an eagle are both animals; calling
#                               them "the same family" reads badly)
#   category NAME: w1 w2 ...    each word is a kind of NAME, and the words are
#                               one family. "kind" passes up the categories
#                               (eagle -> bird -> animal: eagle is a kind of
#                               animal); "family" needs the SAME category
#                               (eagle/owl yes, eagle/dog no).
#                               ~NAME is a family with no word of its own
#                               (~vehicle: car, bus... but "vehicle" isn't a tile).
#   family: w1 w2 ...           a family that needs no category
#   avoid: a b                  never put a and b on one board: a real phrase
#                               that isn't one of the six types (fruit salad
#                               + banana), so players would try it and strike
#   ?word                       in any list: the link(s) the line gives that word
#                               are arguable (true, but some players would
#                               hesitate). Accepted when played; never used to
#                               build a puzzle's intended route.
#   A REL: b c d                one line per word and relation, REL in
#                               part made feature use makes in with kind
#                               (made -> part, makes -> use, in/with -> found)
#
# One word, one meaning
#   A word's links all describe the same thing. Words with two strong,
#   unrelated meanings (orange: the colour and the fruit) are left out
#   altogether: keeping one meaning would strike players for the other,
#   which they can't un-know. Related meanings are fine: a drinking glass is
#   made of glass, so cup -> glass -> sand is one thing, not a pun.
#   Watch: spring (season / water / coil), light (noun / not heavy) are kept
#   with one meaning each; the board check should catch the other.
