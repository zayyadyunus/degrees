    Notes on this board

    Six links from start to target, five words between. Each link type can be spent once. Back returns the type. Playing a link whose type is already spent, or a tile that doesn't link, costs a strike; three strikes ends the board. Hint names the type to spend next. Tap a word in your chain to go back to it.
